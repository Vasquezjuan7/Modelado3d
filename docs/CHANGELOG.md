# Changelog

## 2.1.0

### Nuevo
- Base de datos en la nube (Supabase) integrada: cuentas reales sin configurar nada.
- Sincronización de tema, idioma y calidad gráfica con la cuenta.
- Sincronización de los repos recientes entre equipos.
- Historial de auditorías en el menú de usuario, con opción de borrar y de saltar al edificio.
- Aviso de confirmación de correo al crear cuenta y mensajes de error de inicio de sesión en español.

### Compilación
- `build-linux-wsl.ps1` / `scripts/build-linux.sh`: paquetes de Linux desde Windows con WSL.
- CI fijada a Ubuntu 24.04 para los paquetes de Linux.

## 2.0.0
- Primera versión de escritorio para Windows, macOS y Linux.
